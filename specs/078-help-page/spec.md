# A help page, opened from the `?` at the right end of line 3

**Feature Branch**: `feat/073-backlog-batch`

**Created**: 2026-11-05

**Input**: "crie uma página de help, no mesmo estilo e cores do statusline para ser instalado junto com o
statusline e adicione um icone de help no fim da terceira linha, no canto direito … explicando o que
significa cada informação exibida pelo statusline, de forma bem detalhada usando /humanizer … com
opção de pt-br, inglês, francês e espanhol, onde o default é conforme o browser do usuário ou inglês …
a página usará a lib i18n … esta página html não pode em nenhuma hipótese usar design system de empresa."

## Requirements

- **FR-001**: `help/index.html` ships in the install (the clone, and the package's `files`). It is
  generated by `scripts/generate-help.js` from the segment registry, the glyph outlines and the
  mocha palette: a card per segment with its chip drawn as the bar draws it, then sections on how
  to read the bar, the missing, old and estimated states, the rows after the bar, and the switches.
- **FR-002**: The words live in `help/locales/{en,pt-BR,fr,es}.js`, written under the humanizer's
  rules (English and Portuguese first, French and Spanish from them). Every segment has a title
  and an explanation in all four; a test fails when a segment or a key is missing in any language.
- **FR-003**: i18next and its browser language detector, vendored in `help/vendor` with their MIT
  licences, choose the language: the `?lng=` query, then the reader's last choice (kept in the
  browser), then the browser's languages; any `pt-*` is Brazilian Portuguese, other languages keep
  their base code, and English is the fallback. A selector on the page changes it.
- **FR-004**: The page is opened from disk: no network request, no CDN, no web font, no `fetch`.
  It uses the statusline's own colours and no company design system or branding.
- **FR-005**: Segment `help` (line 3, last, right-aligned, priority 40, `pinned`: always drawn at the right end of line 3, never dropped for width; the other chips make room for it. The chip links to the https page published on GitHub Pages (`https://jonyfs.github.io/statusline/help/`, from `help/` by `.github/workflows/pages.yml`), since a terminal opens a `file://` link in the file manager instead of the browser. Glyph: nf-fa-question_circle)
  draws the help glyph (`?` in the plain tier, ❓ in emoji) as a link to the page, only when the
  page exists beside the code. `CLAUDE_STATUSLINE_OMIT=help` removes it.
- **FR-006**: specs/020 keeps links in the reader's project; this link to the plugin's own file is
  the exception the owner asked for, and the links test names it.

Data in the rows comes from a live probe on 2026-10-06: a pre-commit in the main barbershop checkout running gates.sh, then review-cycle.test.sh, for 3 minutes, holding .git/gates.lock.

Claude Code possible

As implemented: a count on line 1, and one row per running gate after the bar. * marks this worktree; a run waiting for another run's lock has its own icon and says so.

A window too short for the rows: they go first, before any line of the bar, and the count stays. They return when there is room.

GitHub Copilot CLI possible

Same output, after the subagent rows from specs/030. Copilot draws every line the command prints.

OpenAI Codex CLI not in its footer

Codex 0.160.1 runs no outside command in its status line: [tui] status_line is a fixed list of built-in items on one line, and none of them is about git hooks. The rows cannot appear there. What it would look like today is unchanged:
